# kotobad 登壇スライド

技育展2026 オンライン予選 (F ブロック) 用のスライドです。
3 パターンで提供しています。

## ディレクトリ

- `html/` — 素の HTML スライド (`index.html`)。ブラウザで開くだけで動作。矢印キー / Space で移動。
- `slidev/` — Slidev 用 (`slides.md`)。`npm install && npm run dev` で起動。
- `marp/` — Marp 用 (`slides.md`)。`npm install && npm run dev` で起動、`npm run build` で HTML 出力。
- `assets/` — 共通画像・ロゴ素材。各サブディレクトリにもコピー済み。

## 共通素材

実際のアプリ画面のスクリーンショット、ロゴ、技術ロゴ (simpleicons) を `assets/` に収録。
